# BISHI — Premium Community Savings & Accountability Platform
**"Traditional Bishi. A New Standard of Trust."**

BISHI modernizes the traditional Indian Bishi system (Rotating Savings and Credit Association / ROSCA) into a centralized, transparent, and verifiable digital ecosystem.

Built with **React 19**, **TypeScript**, **Tailwind CSS**, and **Three.js**, with a cryptographic consortium verification layer.

---

## 🌟 Key Features

- **Non-Auction Guarantee**: 100% principal savings circle without predatory auctions or bidding haircuts.
- **3D Visual Experience**:
  - **Hero Savings Vault**: Interactive 3D metallic coin torus with rotating core and particle dynamics.
  - **Community Circle 3D**: Orbital 3D node visualizer showing members, organizer hub, and payout pulse milestones.
- **Multi-Role Governance**: Switchable role-tailored dashboards for **Bishi Organizer**, **Circle Member**, **Independent Auditor**, and **Platform Admin**.
- **Cryptographic Record Anchoring**: Every contribution receipt, payout settlement, and charter agreement generates a deterministic SHA-256 digest anchored to a simulated consortium ledger.
- **Interactive Tamper Detection Sandbox**: Live interactive sandbox demonstrating how changing even one character breaks document hash verification.
- **Global Command Palette**: Instant navigation and entity search with `⌘K` / `Ctrl+K`.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Bhishiiiiii/Bhishi-Frontend.git
cd Bhishi-Frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
npm run preview
```
